# Dr Mansur Biópsias - Landing Page

Uma landing page médica moderna, responsiva e de alta performance desenvolvida para a clínica do Dr. Mansur, especialista em pequenas cirurgias e biópsias no Rio de Janeiro.

O projeto foca em conversão (agendamento via WhatsApp), acessibilidade e uma apresentação visual limpa que transmite autoridade e confiança médica.

## 🚀 Tecnologias Utilizadas

- **React 18** (via Vite): Para uma interface de usuário rápida e reativa.
- **TypeScript**: Para tipagem estática e código mais seguro.
- **Tailwind CSS**: Estilização utilitária (implementada via CDN para leveza neste setup).
- **Lucide React**: Biblioteca de ícones moderna e leve.
- **GitHub Raw Assets**: Hospedagem otimizada de imagens.

## ✨ Funcionalidades

- **Design Responsivo**: Adaptação perfeita para mobile, tablets e desktop.
- **Integração com WhatsApp**: Botões de CTA (Call to Action) configurados com mensagens pré-definidas que direcionam para o WhatsApp do médico.
- **Galeria de Casos**: Exibição de tratamentos realizados carregados via CDN.
- **Menu Mobile Interativo**: Navegação fluida com backdrop blur.
- **Performance**: Otimização de carregamento de fontes e imagens.

## 📂 Estrutura do Projeto

```
/
├── src/
│   ├── components/   # Componentes React (Header, Hero, Gallery, etc)
│   ├── constants.ts  # Dados estáticos (Info do médico, serviços)
│   ├── types.ts      # Definições de tipos TypeScript
│   ├── App.tsx       # Componente principal
│   └── main.tsx      # Ponto de entrada
├── index.html        # Template HTML principal
└── vite.config.ts    # Configuração do bundler
```

## 🛠️ Como Rodar o Projeto

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

3. **Para gerar o build de produção:**
   ```bash
   npm run build
   ```
